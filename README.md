# Python Practice

Small Python tasks from my discrete math course: sets, logic and recursion.

| File | What it does |
|---|---|
| `task1_subsets.py` | Generates all subsets of a set |
| `task2_XNOR.py` | XNOR of two boolean values |
| `task3_next_smaller_number.py` | Next smaller number with the same digits |
| `task4_truth_table.py` | Prints a truth table for a boolean expression |
| `task5_sierpinski_carpet.py` | Draws a Sierpinski carpet of depth n |

## How to run

```bash
python task4_truth_table.py
```
